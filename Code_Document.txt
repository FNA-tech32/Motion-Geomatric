# Motion Geomatric - Website Documentation

## Introduction
This document provides an overview of the code structure, architecture, and functionality of the **Motion Geomatric** logistics and shipping web platform. The website showcases Motion Geomatric's global logistics profile through a modern, engaging interface with responsive layouts, multimedia video integration, interactive sliders, and dedicated service portals.

## Website Theme & Identity
1. **Brand Identity**: Motion Geomatric – Global Shipping & Logistics Solutions.
2. **Homepage**: Features hero video playback transitioning into a dynamic image slider, followed by service highlights, core competitive advantages, and the Managing Director's address.
3. **Animations & Transitions**: CSS3 animations and Ionicons transitions enhance UX across devices.
4. **Credential Portals**: Clean user login, registration, and password recovery interface templates.
5. **Comprehensive Service Suite**: Dedicated pages for each logistics vertical including Ocean Freight, Road Transport, Air Freight, Customs Clearance, Special Equipment (ODC), Warehousing, Door-to-Door Delivery, and Allied Services.
6. **Cargo Tracking**: Real-time cargo tracking interface powered by the Motion Eye Watch system.
7. **Contact & Quote System**: Web3Forms-integrated contact and quotation submission form featuring primary and alternative contact channels.
